Privacy Policy

Last updated: November 17, 2026

This policy explains how the Video Otomasyon prototype handles information when generating short-form videos and, if later enabled and authorized, connecting to social platforms.

Information processed

The current video-generation workflow processes prompts, generated scripts, captions, search terms, audio, and downloaded stock-media files. It uses an OpenAI API key to request text and speech generation and a Pixabay API key to search for stock videos. The workflow runs through GitHub Actions and may retain generated output files as temporary workflow artifacts for a limited period.

Social account information

The current workflow does not yet automatically publish to TikTok or YouTube. If a social-platform integration is later enabled, the service will process the authorization tokens and the content and account information needed to perform the action you request. Platform providers process information under their own privacy policies. You can revoke platform access through the relevant platform settings.

How information is used

Information is used to generate video scripts and narration, find relevant stock media, assemble video files, troubleshoot failures, and carry out publishing actions only when the relevant integration is enabled and authorized.

Storage and sharing

API credentials should be stored as private repository secrets and must not be placed in source code or public logs. Generated files may be stored temporarily as GitHub Actions artifacts. Information is sent to the third-party providers required for the requested functions. We do not sell personal information.

Retention and security

Temporary workflow artifacts are configured with a short retention period. Logs may remain available according to GitHub's retention settings. Reasonable steps are taken to protect credentials, but no online service can guarantee absolute security. Never share passwords, client secrets, or access tokens.

Your choices

You may stop using the workflow, delete generated artifacts where available, remove stored repository secrets, or revoke social-platform authorization. Requests about information handled by third-party providers must be directed to those providers.

Children

This prototype is not intended for children under 13 and is not designed to knowingly collect children's personal information.

Changes and contact

This policy may be updated as features change. For questions, use the contact method provided in the project repository.
